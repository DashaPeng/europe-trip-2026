# 2026 歐洲旅行一頁式網站

這個資料夾可直接部署到 GitHub Pages。

## 上線方式
1. 在 GitHub 建立一個新的 repository。
2. 把 `index.html` 與 `assets/` 整個上傳到 repository 根目錄。
3. GitHub → Settings → Pages。
4. Build and deployment 選 `Deploy from a branch`。
5. Branch 選 `main`，Folder 選 `/ (root)`，按 Save。
6. 等待約 1–3 分鐘，GitHub 會顯示網站網址。

首頁檔案必須維持名稱：`index.html`
